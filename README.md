<p><strong>CodeSmartDNSTester</strong> (aka. CodeSmart DNS Tester) is a completely free, lightweight and portable Windows app, designed to speed-test popular and custom DNS resolvers, display current active DNS configurations, and automatically apply the fastest and most optimum server found to your network adapter in one click.</p>

<p><strong>App Usage:</strong><br>
<ul>
    <li>Run the app, on a system with internet access</li>
    <li>The app will display your current DNS and the popular DNS resolvers in a table
    <li>Click the "Start Speed Test" button to start the DNS speed test. Let the test complete</li>
    <li>The app will sort the DNS resolvers with respect to speed and let you know if you are using the fastest DNS or not</li>
    <li>You can also select any DNS row and click "Apply Selected DNS". This will setup your system to use the selected DNS resolver</li>
    <li>You can also add any DNS resolvers to the list</li>
    <li>You can export the DNS speed results in a csv file by clicking the "Export Results to CSV" button</li>
</ul>
</p>
<br>
<p><strong>Compatibility:</strong><br>
<ul>
    <li>Windows 11 (64 bit and ARM64)</li>
    <li>Windows 10 (32 and 64 bit)</li>
    <li>Windows 8 / Windows 7 (Fully functional provided the .NET Framework 4.8 runtime is installed on the system).</li>
</ul>
</p>
<br>
<p><strong>System & Framework Requirements:</strong><br>
<ol>
    <li>Runtime: Requires .NET Framework 4.8 (pre-installed natively on modern Windows 10/11 updates).</li>
    <li>Permissions: Requires Administrator privileges in order to change the current system DNS.</li>
</ol>
</p>

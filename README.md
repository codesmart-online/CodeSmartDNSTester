CodeSmartDNSTester (aka. CodeSmart DNS Tester) is a completely free, lightweight and portable Windows app, written in C#; designed to speed-test popular and custom DNS resolvers, display current active DNS configurations, and automatically apply the fastest and most optimum server found to your network adapter in one click.

App Usage:
    1. Run the app, on a system with internet access
    2. The app will display your current DNS and the popular DNS resolvers in a table
    3. Click the "Start Speed Test" button to start the DNS speed test. Let the test complete
    4. The app will sort the DNS resolvers with respect to speed and let you know if you are using the fastest DNS or not
    5. You can also select any DNS row and click "Apply Selected DNS". This will setup your system to use the selected DNS resolver
    6. You can also add any DNS resolvers to the list
    7. You can export the DNS speed results in a csv file by clicking the "Exort Results to CSV" button

Compatibility:
    1. Windows 7 / Windows 8 (Fully functional provided the .NET Framework 4.8 runtime is installed on the system).
    2. Windows 11 (64-bit).
    3. Windows 10 (both 32-bit and 64-bit architectures).

System & Framework Requirements:
    1. Runtime: Requires .NET Framework 4.8 (pre-installed natively on modern Windows 10/11 updates).
    2. Permissions: Requires Administrator privileges to change the current system DNS.
